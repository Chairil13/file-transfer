FILE TRANSFER Transfer File Kode QR Fountain (PoC)

Kirim file antara dua perangkat hanya menggunakan layar dan kamera. Buka mode Kirim pada perangkat yang menyimpan file (seperti laptop) dan mode Terima pada HP, lalu arahkan kamera HP ke kode QR yang berkedip.

📡

Kirim File (Mode Sender)

Buka di perangkat pengirim (laptop/PC). Pilih file atau contoh data untuk memancarkan stream kode QR animasi berkecepatan tinggi pada layar.

Buka Mode Kirim →
📷

Terima File (Mode Receiver)

Buka di perangkat penerima (smartphone/tablet). Arahkan kamera ke layar pengirim untuk menangkap frame & menyusun kembali file asli.

Buka Mode Terima →
🛡️
Keamanan Air-Gapped
Tidak memerlukan Wi-Fi, Bluetooth, atau Internet. Data mengalir murni sebagai gelombang cahaya antar layar.
🌊
Fountain Coding
Penerima dapat menangkap frame secara acak dalam urutan apapun dan tetap dapat menyusun file lengkap.
⚡
Stream Adaptif
Kecepatan frame rate dapat disesuaikan (hingga 60 FPS) dan tingkat koreksi error untuk kecepatan transfer tinggi.
📱
Lintas Perangkat
Berjalan langsung di browser modern pada HP Android, iOS, Laptop, PC, dan Tablet tanpa perlu aplikasi tambahan.
